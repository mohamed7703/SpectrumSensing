# Fresh synthetic benchmark v1
Frozen before evaluating fresh scores. Use the accompanying [YAML configuration](../../experiments/configs/calibration_benchmark_v1.yaml). The primary question is improved 0 dB detection at equal calibration cost.

- Train five GAP models with independent initializations, independently seeded QPSK training and validation frames and best-validation checkpoints. Run three independent calibration/test session pairs per model. Unit nominal complex noise power, 1024 samples per frame, common receiver amplitude scale 10^(gain/20). Separate exploratory noise stress adds 1 dB to noise power at fixed nominal signal power. Numerical simulation alone cannot reproduce physical session drift.
- Generate 400 independent H0 frames per training gain (−1, 0, +1 dB) per session. Nested prefixes give budgets of 100, 200 and 400. Use the same frames for competing methods. Export quantizer representative frames come from training only.
- Fit the existing strict 95%-confidence H0 order statistic at 5% target for each gain. Ordinary INT8 uses that local boundary. Candidate fits unweighted least squares of the three **observed order-statistic scores** on gain, then rejects scores strictly above the fitted line (round numerical noise at 12 decimals for discrete scores). Nominal INT8 uses all 3B samples taken separately at 0 dB and transfers its threshold. Native FP32 and energy use independent per-gain thresholds from the same calibration frames. Ordinary thresholds at the exploratory +0.5 dB gain transfer from the nearest calibrated gain, breaking ties toward lower gain.
- Independently score 300 H0 and 80 H1 per SNR per test condition. Primary analysis uses B=200 per calibration gain (600 total), equal weights across −1, 0, +1 dB, 0 dB SNR, nominal noise. Report all other budgets, SNRs, held-out gain, and noise stress as secondary. Each simulated session uses independent raw test frames per condition, paired exactly across methods.
- For each model compute the average paired Pd difference across its sessions and primary gains. Use a two-sided 95% t interval over the five independent model blocks. At each primary gain compute candidate and ordinary Pfa by model, using the larger of a one-sided t upper bound over blocks and the pooled exact binomial upper bound, with Bonferroni alpha 0.05/6 across two methods and three gains. Pooled binomial bounds assume independent trials conditional on the fitted rules; the combined gate is an approximate synthetic screening criterion. Recommend testing superiority only if both methods satisfy the false-alarm gate and the lower Pd-difference bound exceeds zero. Zero improvement is the prespecified minimum; practical importance depends on the magnitude. Otherwise revise or limit the pilot to characterizing the failure.
