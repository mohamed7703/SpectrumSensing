# Test-by-test technical audit

Each of the 205 collected pytest cases passed. Audit status judges what its evidence supports, rather than repeating the pytest outcome. Verified means the narrow stated unit behavior was checked; it never means the entire method is correct. Failed means the reported scientific interpretation is contradicted, even when its weak software assertion passed. Partially Verified means limited evidence. Inconclusive means no applicable reproducible evidence.
